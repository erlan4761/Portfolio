# Erlan — портфолио и продажа готовых сайтов

Одностраничный сайт-витрина для клиентов из Бишкека: работы, преимущества, услуги, процесс и форма заказа. RU по умолчанию, переключатель EN.

**Стек:** HTML, CSS (дизайн-токены, без фреймворков), Vanilla JS, GSAP ScrollTrigger + Lenis (CDN), Formspree для формы. Сборка не нужна — открывается как статика (GitHub Pages, Netlify, любой хостинг).

## Структура

```
index.html        — разметка всех секций
css/style.css     — дизайн-система: токены → компоненты → секции → адаптив
js/i18n.js        — словарь RU/EN и переключатель языка
js/projects.js    — данные проектов и рендер карточек
js/main.js        — плавный скролл, анимации, навигация, форма
img/projects/     — скриншоты работ
```

## Что заменить перед публикацией

1. **Форма.** В `index.html` найдите `YOUR_FORM_ID` и вставьте ID формы с [formspree.io](https://formspree.io) (бесплатный план — 50 заявок в месяц).
2. **Telegram.** Замените `USERNAME` в ссылке `https://t.me/USERNAME` и в подписи `@USERNAME` (секция «Заказ»).
3. **WhatsApp.** Номер в `https://wa.me/79773552841` и в подписи — если нужен другой.
4. **ARKA.** Опубликован на GitHub Pages, ссылка уже в `js/projects.js`. Если у проекта нет живой ссылки — оставьте `url: ''` и укажите `repo`: кнопка станет «Код на GitHub».
5. **Статус в hero** («Принимаю заказы на сентябрь») — в `js/i18n.js`, ключ `hero.status` (RU и EN) и в `index.html`.

## Как добавить проект

1. Сделайте два скриншота сайта шириной 1440px: обычный (`<id>.jpg`, 1440×900) и длинный (`<id>-full.jpg`, вся страница) — положите в `img/projects/`.
2. Добавьте объект в массив `PROJECTS` в `js/projects.js` по образцу: ссылка, стек, и тексты на RU и EN (название, теги, описание, 3–4 пункта «что это даёт бизнесу»).

Карточка появится сама; при наведении длинный скриншот прокручивается внутри окна браузера.

## Локальный просмотр

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Параметр `?noanim` отключает анимации (удобно для скриншотов).
