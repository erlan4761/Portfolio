# Erlan — портфолио и продажа готовых сайтов

Одностраничный сайт-витрина для клиентов из Бишкека: работы, преимущества, услуги, процесс и форма заказа. RU по умолчанию, переключатель EN.

**Стек:** HTML, CSS (дизайн-токены, без фреймворков), Vanilla JS, GSAP ScrollTrigger (CDN), Formspree для формы. Сборка не нужна — открывается как статика (GitHub Pages, Netlify, любой хостинг).

## Структура

```
index.html        — разметка всех секций
css/style.css     — дизайн-система: токены → компоненты → секции → адаптив
js/i18n.js        — словарь RU/EN и переключатель языка
js/projects.js    — данные проектов и рендер карточек
js/main.js        — анимации, навигация, форма
img/projects/     — скриншоты работ
```

## Настройки

- **Форма** — Formspree, ID формы в атрибуте `action` у `<form id="order-form">` в `index.html`. Заявки приходят на почту, указанную в аккаунте Formspree.
- **Контакты** — ссылки Telegram и WhatsApp в секции «Заказ» (`index.html`, блок `<ul class="contacts">`).
- **Статус в hero** («Принимаю заказы на сентябрь») — ключ `hero.status` в `js/i18n.js` (RU и EN) и текст в `index.html`.

## Как добавить проект

1. Сделайте два скриншота сайта шириной 1440px: обычный (`<id>.jpg`, 1440×900) и длинный (`<id>-full.jpg`, вся страница) — положите в `img/projects/`.
2. Добавьте объект в массив `PROJECTS` в `js/projects.js` по образцу: ссылка, стек, и тексты на RU и EN (название, теги, описание, 3–4 пункта «что это даёт бизнесу»).

Карточка появится сама; при наведении длинный скриншот прокручивается внутри окна браузера.

## Локальный просмотр

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Параметр `?noanim` отключает анимации (удобно для скриншотов).
